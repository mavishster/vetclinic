# ADR-014. Подтверждение операций ПИН-кодом

- **Статус:** принято
- **Дата:** 28.10.2026

## Контекст
Кассовые операции, откаты и удаления нужно подтверждать; за общим компьютером важно, кто именно провёл операцию.

## Решение
У сотрудника есть короткий ПИН (4–6 цифр) для подтверждения. Пароль — для входа и административных операций.

## Альтернативы
Пароль на каждую операцию — медленно, сотрудники начинают обходить; без подтверждения — непонятно, кто провёл.

## Последствия
Один механизм подтверждения в ядре для всех модулей.

## Реализация (этап 1, шаг 3)
- ПИН — 4–6 цифр; одинаковые цифры и последовательности (0000, 1234, 4321) запрещены. Хранится только хеш.
- Задаёт сам сотрудник, подтверждая паролем (`POST /api/core/me/pin/`). Администратор может только сбросить.
- Проверка — `core.services.confirm_action(user, pin)`; после 5 неверных попыток блокировка на 15 минут (`PIN_MAX_ATTEMPTS`, `PIN_LOCK_MINUTES`).
