# ADR-014. Подтверждение операций ПИН-кодом

- **Статус:** принято
- **Дата:** 28.10.2026

## Контекст
Кассовые операции, откаты и удаления нужно подтверждать; за общим компьютером важно, кто именно провёл операцию.

## Решение
У сотрудника есть короткий ПИН (4–6 цифр) для подтверждения. Пароль — для входа и административных операций.

## Альтернативы
Пароль на каждую операцию — медленно, сотрудники начинают обходить; без подтверждения — непонятно, кто провёл.

## Последствия
Один механизм подтверждения в ядре для всех модулей.
