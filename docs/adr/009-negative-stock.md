# ADR-009. Продажа в минус без временных партий

- **Статус:** принято
- **Дата:** 28.10.2026

## Контекст
Иногда товар продают раньше, чем оформлен приход.

## Решение
Если продажа в минус разрешена, списание записывается с признаком «себестоимость ожидается»; следующий приход закрывает его по реальной цене и уточняет себестоимость в строке счёта.

## Альтернативы
Временные партии с нулевой себестоимостью (VetManager) — искажают прибыль и запутывают учёт.

## Последствия
Себестоимость точна даже при продаже в минус.

## Реализация (этап 3, шаг 5б) — упрощение
Клиника разрешила продажу в минус. Вместо отдельных «ожидающих» движений без партии:
недостающее списывается с **последней партии** товара по её закупочной цене (это и есть
оценка себестоимости), партия уходит в минус. Приход того же товара на тот же склад сразу
«переносит» количество из новой партии в партии с минусом — проводками самого прихода,
поэтому откат прихода их тоже отменит. Себестоимость проданного в минус не пересчитывается
по цене нового прихода: разница обычно мала, а схема остаётся простой и проверяемой (KISS).
Настройка — `ALLOW_NEGATIVE_STOCK` (по умолчанию включена); при выключенной — понятная ошибка.
