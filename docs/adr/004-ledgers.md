# ADR-004. Журналы движений

- **Статус:** принято
- **Дата:** 28.10.2026

## Контекст
Остатки товара, деньги в кассе, баланс клиента, долги поставщикам должны быть точными и проверяемыми.

## Решение
Остатки и балансы вычисляются из журналов, в которые записи только добавляются. Кэш остатков обновляется в той же транзакции и всегда может быть пересчитан из журнала.

## Альтернативы
Редактируемое поле «остаток» — расходится с реальностью, ошибку невозможно найти.

## Последствия
Любой остаток объясним до отдельной операции; отчёты «на дату» получаются бесплатно.
