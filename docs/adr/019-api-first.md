# ADR-019. API-first

- **Статус:** принято
- **Дата:** 28.10.2026

## Контекст
Будут мобильное приложение и голосовой ввод.

## Решение
Любое действие системы доступно через API. Веб-интерфейс — один из клиентов API.

## Альтернативы
Логика в серверных шаблонах — мобильное приложение потребует переписывания.

## Последствия
Новые клиенты (мобильный, голосовой) добавляются без изменения бизнес-логики.
