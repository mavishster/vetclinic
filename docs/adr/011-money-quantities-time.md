# ADR-011. Деньги, количества, время

- **Статус:** принято
- **Дата:** 28.10.2026

## Контекст
Ошибки округления в деньгах недопустимы; клиника работает в своём часовом поясе.

## Решение
Деньги — `Decimal(12,2)`, количества — `Decimal(14,3)`. Дробные числа (float) для денег и количеств запрещены. Время хранится с часовым поясом.

## Альтернативы
float — ошибки округления.

## Последствия
Единые типы полей определены в ядре и используются всеми модулями.
