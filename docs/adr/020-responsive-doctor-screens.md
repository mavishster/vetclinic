# ADR-020. Адаптивные экраны врача

- **Статус:** принято
- **Дата:** 28.10.2026

## Контекст
Врачи будут работать с телефона и планшета (обход стационара, медкарта).

## Решение
Медкарта, календарь, стационар, карточка пациента с самого начала работают на телефоне и планшете.

## Альтернативы
Сначала только под монитор — потом переверстка всего интерфейса врача.

## Последствия
Чуть больше работы на этапе 3, мобильная версия на этапе 8 — почти бесплатна.
