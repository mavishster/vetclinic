# ADR-021. Всё в Linux-контейнерах

- **Статус:** принято
- **Дата:** 28.10.2026

## Контекст
Разработка на macOS, сервер клиники — на Windows (редакция пока неизвестна).

## Решение
Всё работает в Docker-контейнерах Linux; код не зависит от ОС. На сервере — Ubuntu в Hyper-V (рекомендуется) или Docker Desktop + WSL2. Драйвер ККТ — на Windows-хосте, контейнер обращается к нему по сети.

## Альтернативы
Запуск напрямую в Windows — разное поведение на машине разработчика и сервере.

## Последствия
Единые переводы строк (`.gitattributes`), данные БД — в томе Docker, автоперезапуск контейнеров.
