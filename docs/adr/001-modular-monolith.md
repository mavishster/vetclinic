# ADR-001. Модульный монолит

- **Статус:** принято
- **Дата:** 28.10.2026

## Контекст
Нужна система из многих связанных модулей. Разработчик один, клиника одна, нужна синхронизация с облаком.

## Решение
Одно приложение Django и одна база PostgreSQL, разделённые на модули с публичным входом (`services.py`) и событиями. Границы проверяет `import-linter`.

## Альтернативы
Микросервисы — кратно сложнее в разработке, развёртывании и синхронизации без выгоды для одной клиники. Монолит без границ — быстро превращается в клубок.

## Последствия
Модули можно развивать независимо; связи между ними — только через узкие стыки (PROJECT_PLAN, раздел 7).
