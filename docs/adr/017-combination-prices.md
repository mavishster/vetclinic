# ADR-017. Цены в комбинациях

- **Статус:** принято
- **Дата:** 28.10.2026

## Контекст
Синхронизация цен комбинаций в VetManager запутанна.

## Решение
У позиции комбинации поле `price_override`: пусто — текущая цена прайса; задано — фиксированная цена. «Сбросить цены» = очистить.

## Альтернативы
Копировать цены в комбинацию и спрашивать «обновить?» при каждом изменении прайса.

## Последствия
Одно правило, никаких вопросов при изменении прайса.

## Реализация (этап 2, шаг 5)
- `CombinationLine.price_override` (пусто — цена прайса), `catalog.services.expand_combination()` для счёта, `combination_price()`, `reset_combination_prices()`.
- Вложенные комбинации запрещены; цена комбинации неизвестна, если неизвестна цена хотя бы одной позиции (товар с наценкой без закупочной цены).
