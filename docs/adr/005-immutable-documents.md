# ADR-005. Неизменяемость проведённых документов

- **Статус:** принято
- **Дата:** 28.10.2026

## Контекст
Финансовые и складские документы — основа отчётности.

## Решение
Выполненный документ не редактируется. Исправление — откатом (если нет зависимых движений) или документом-корректировкой.

## Альтернативы
Свободное редактирование — задним числом меняет отчёты и остатки.

## Последствия
Больше документов, зато вся история изменений видна.
