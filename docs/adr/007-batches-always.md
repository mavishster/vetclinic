# ADR-007. Партии ведутся всегда

- **Статус:** принято
- **Дата:** 28.10.2026

## Контекст
Нужны сроки годности, фактическая себестоимость, серии вакцин в медкарте.

## Решение
Каждый приход создаёт партии. Настройка «показывать партии» только прячет их в интерфейсе.

## Альтернативы
Включаемый учёт партий — две разные логики склада.

## Последствия
Одна логика склада; сроки годности и серии работают всегда.
