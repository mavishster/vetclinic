# ADR-012. Нумерация документов с префиксом узла

- **Статус:** принято
- **Дата:** 28.10.2026

## Контекст
Документы создаются на разных узлах (локальный сервер, позже — облако или второй филиал).

## Решение
Номер документа = префикс узла + порядковый номер по типу документа (`К1-000123`). Выдаётся одной функцией ядра.

## Альтернативы
Сквозные номера без префикса — конфликтуют при синхронизации.

## Последствия
Номера уникальны и читаемы.
