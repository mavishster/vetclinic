# ADR-013. Модель прав

- **Статус:** принято
- **Дата:** 28.10.2026

## Контекст
Разные сотрудники — разные доступы; часть действий требует отдельных разрешений.

## Решение
Роль × модуль × действие (просмотр, редактирование, удаление, администрирование) + точечные права (например, «проводить документы по любым складам»).

## Альтернативы
Только роли без действий — слишком грубо; права на каждое поле — слишком сложно.

## Последствия
Строится на стандартных правах и группах Django.
