# ADR-002. UUID-ключи и поля синхронизации

- **Статус:** принято
- **Дата:** 28.10.2026

## Контекст
Данные создаются на локальном сервере и выгружаются в облако; позже возможна двусторонняя синхронизация и второй филиал.

## Решение
Все таблицы проекта: `id` (UUID), `created_at`, `updated_at`, `created_by`, `updated_by`, `version`, `is_deleted`, `node_id`, `clinic_id`. Реализуется один раз в базовой модели ядра.

## Альтернативы
Автоинкрементные ключи — конфликтуют при слиянии данных с разных узлов; добавить UUID позже — переписать все связи.

## Последствия
Чуть больше места в БД; ключи нечитаемы для людей — для людей есть номера документов (ADR-012).
