# ADR-003. Мягкое удаление

- **Статус:** принято
- **Дата:** 28.10.2026

## Контекст
Синхронизации нужно знать об удалениях; медицинские и финансовые данные нельзя терять.

## Решение
Физически ничего не удаляется. «Удалить» = пометить `is_deleted` / деактивировать. Восстановление — снятие пометки.

## Альтернативы
Физическое удаление — ломает синхронизацию и историю.

## Последствия
Все выборки по умолчанию исключают удалённые записи (менеджер модели в ядре).
