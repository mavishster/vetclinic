# ADR-006. Остатки в базовых единицах

- **Статус:** принято
- **Дата:** 28.10.2026

## Контекст
Клиника часто продаёт препараты частями (таблетки, мл).

## Решение
Склад хранит остатки в самой мелкой единице товара. Упаковки и другие единицы — только пересчёт по коэффициенту.

## Альтернативы
Хранить в упаковках с дробями (как VetManager) — накапливаются ошибки округления (1/216 упаковки).

## Последствия
Ввод и отображение — в любых единицах; учёт — точный.
