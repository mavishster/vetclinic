# ADR-016. Наценка: пусто = наследовать

- **Статус:** принято
- **Дата:** 28.10.2026

## Контекст
В VetManager 0% наценки означает «брать наценку группы», поэтому реальную наценку 0% поставить нельзя.

## Решение
Пустое значение наценки — наследовать от группы; 0 — действительно 0%.

## Альтернативы
Магическое значение 0 — путаница.

## Последствия
Явная семантика, без исключений в коде.
