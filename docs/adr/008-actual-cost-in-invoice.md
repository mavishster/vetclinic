# ADR-008. Фактическая себестоимость в строке счёта

- **Статус:** принято
- **Дата:** 28.10.2026

## Контекст
Отчёты о прибыли должны быть точными.

## Решение
При списании в строку счёта записывается закупочная цена списанной партии.

## Альтернативы
Себестоимость «по FIFO на момент отчёта» — условна и меняется задним числом.

## Последствия
Прибыль по любому счёту известна сразу и не меняется.
